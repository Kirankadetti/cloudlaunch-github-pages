\# CloudLaunch — From Code to Cloud



CloudLaunch is a responsive static website built to demonstrate how to host and publish a website using GitHub Pages.



\## Project Overview



The project uses HTML, CSS, and JavaScript to demonstrate a static website deployment workflow with Git and GitHub.



\## Technology Stack



\- \*\*HTML5\*\* — page structure and content

\- \*\*CSS3\*\* — responsive layout and styling

\- \*\*JavaScript\*\* — navigation interactions and dynamic footer year

\- \*\*Git\*\* — local version control

\- \*\*GitHub\*\* — source code repository

\- \*\*GitHub Pages\*\* — static website hosting



\## Project Structure



```text

github-pages-devops-site/

├── index.html

├── style.css

├── script.js

└── README.md

```



\## Deployment Workflow



1\. Develop and test the website locally.

2\. Track changes using Git.

3\. Push the project to a GitHub repository.

4\. Enable GitHub Pages in repository settings.

5\. Publish from the `main` branch and root directory.

6\. Verify the public website URL.



\## Hosting Considerations



GitHub Pages is designed for static website hosting. It does not execute server-side application code or host a backend database.



\## Updating the Website



Modify the source files, commit the changes, and push them to the configured branch. GitHub Pages will publish the updated content after deployment completes.



\## Deployment Status



The website will be marked as deployed after GitHub Pages is enabled and the public URL has been verified.



\## Learning Outcomes



\- Understand static website hosting.

\- Practice Git version control and GitHub repository management.

\- Configure GitHub Pages deployment.

\- Understand the difference between static hosting and backend hosting.
