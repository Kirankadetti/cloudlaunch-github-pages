TECHNICAL KNOWLEDGE

GitHub Pages, explained.

Essential concepts behind static website hosting and deployment.

What is GitHub Pages?

GitHub Pages is a hosting service that publishes static websites directly from a GitHub repository. It supports HTML, CSS, JavaScript, and other static assets.

Can GitHub Pages host a dynamic application?

GitHub Pages does not run server-side application code such as Django, Flask, PHP, or Node.js. A static frontend can communicate with a separately hosted backend API.

How do you update a deployed website?

Edit the source files, commit the changes with Git, and push them to the configured GitHub branch. GitHub Pages then publishes the updated site. Allow time for deployment to finish.

What is the default entry file?

For this project, index.html is the homepage entry file placed at the root of the published directory.

What happens if the repository is deleted?

Deleting the repository removes the source repository and its associated Pages deployment. Keep a backup before deleting a project you want to preserve.

Can GitHub Pages use a custom domain?

Yes. You can configure a domain you own in the repository's Pages settings and update the required DNS records with your domain provider. DNS propagation and HTTPS setup may take time.

What are the hosting limitations?

GitHub Pages is intended for static sites, not server-side processing or databases. Review GitHub's official usage limits before deploying larger or high-traffic projects.
